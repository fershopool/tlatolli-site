# Tlatolli

Sitio estático de una pantalla.

## Estructura

- `index.html`: entrypoint estático de GitHub Pages.
- `frontend/src/pages/inicio/`: estilos y lógica de la pantalla de inicio.
- `frontend/src/styles/`: reset, variables y reglas globales.
- `frontend/src/assets/images/`: imágenes del sitio.
- `docs/arquitectura.md`: guía de arquitectura.

## Abrir y publicar

Abre `index.html` directamente o sirve la carpeta con cualquier servidor estático. Publica la raíz del repositorio en GitHub Pages; `index.html` conserva la URL pública.
