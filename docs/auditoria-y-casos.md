## Observaciones del producto

Tlatolli se presenta como un sistema para construir ecosistemas digitales que atraen clientes, los conocen, los fidelizan, analizan su comportamiento y convierten señales en mejores decisiones de marketing. El ciclo conceptual es: atraer → convertir → identificar → conocer → fidelizar → medir → aprender → volver a atraer.

La interfaz se construye como HTML, CSS y JavaScript vanilla. Las insignias de estado distinguen lo publicado de lo conceptual, beta, capacidad y próximamente.
